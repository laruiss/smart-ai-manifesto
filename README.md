# A Manifesto for Using AI Wisely

AI is an accelerator, not a replacement for clear thinking.

We believe developers are accountable for every line of code they submit, whether they wrote it themselves or it came from an LLM.

Before any submission, code should be:

- **reviewed**: you never assume the model is correct;
- **understood**: you can explain every meaningful decision;
- **tested**: you validate behavior, not just green test runs;
- **simplified**: you remove anything unnecessary or overengineered.

*Code review is not there to catch what the author did not bother to verify.*

AI gives us speed. That speed should be reinvested in understanding, quality, testing, and design, never in producing more code than we can truly own.

**Do not outsource your judgment to a model. Your judgment is exactly what makes you a developer.**

## Contributing

Suggestions and discussions are welcome.

The objective is not to be anti-AI, but to promote responsible AI-assisted software engineering.
