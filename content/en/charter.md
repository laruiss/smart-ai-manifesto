# Charter

AI is an accelerator, not a replacement for clear thinking.

We consider developers accountable for every line of code they submit, whether written by them or generated by an LLM.

Before any submission, code should be:

- **reviewed**: you never assume the model is correct;
- **understood**: you can explain every part of the produced code;
- **tested**: you verify that behavior is correct, not just that tests pass;
- **cleaned**: you remove anything unnecessary or overengineered;
- **clarified**: you ensure the code can be read, understood, and maintained easily by humans.

*Code review is not there to discover what the author did not take the time to verify.*

AI gives us speed. That speed should be reinvested in understanding, quality, testing, and design, never in multiplying code we do not fully control.

**Do not outsource your judgment to a model. That judgment is exactly what makes you a developer.**
