Manifeste pour une utilisation intelligente de l'IA

L'IA est un accélérateur, pas un remplaçant de la réflexion.

Nous considérons qu'un développeur est responsable de chaque ligne de code qu'il soumet, qu'elle ait été écrite par lui ou générée par un LLM.

Avant toute Pull Request, le code doit être :

  • compris : être capable d'expliquer chaque choix important ;
  • relu : ne jamais supposer que le modèle a raison ;
  • testé : vérifier que le comportement est correct, pas seulement que les tests passent ;
  • simplifié : supprimer tout ce qui est inutile ou surconçu.

Une review de code n'a pas pour vocation de découvrir ce que l'auteur n'a pas pris le temps de vérifier.

L'IA nous fait gagner du temps. Ce temps doit être réinvesti dans la compréhension, la qualité, les tests et la conception — jamais dans la multiplication de code non maîtrisé.

Ne déléguez pas votre jugement à un modèle. C'est précisément ce jugement qui fait de vous un développeur.

Contribution

Les suggestions et les discussions sont les bienvenues.

L'objectif n'est pas d'être anti-IA, mais de promouvoir une ingénierie logicielle responsable avec l'IA.

A Manifesto for Using AI Wisely

AI is an accelerator, not a replacement for clear thinking.

We believe developers are accountable for every line of code they submit, whether they wrote it themselves or it came from an LLM.

Before opening any pull request, your code should be:

  • understood: you can explain every meaningful decision;
  • reviewed: you never assume the model is correct;
  • tested: you validate behavior, not just green test runs;
  • simplified: you remove anything unnecessary or overengineered.

Code review is not there to catch what the author did not bother to verify.

AI gives us speed. That speed should be reinvested in understanding, quality, testing, and design, never in producing more code than we can truly own.

Do not outsource your judgment to a model. Your judgment is exactly what makes you a developer.

Contributing

Suggestions and discussions are welcome.

The objective is not to be anti-AI, but to promote responsible AI-assisted software engineering.
